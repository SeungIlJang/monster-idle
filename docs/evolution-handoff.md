# 아트 담당(Codex) 전달 — 몬스터 진화 외형 요청

몬스터가 레벨을 올려도 **그림이 전혀 바뀌지 않습니다.** 지금은 종당 포즈 4장
(`idle_1` · `attack_1` · `hit_1` · `dead_1`)이 전부이고, 렌더러는 레벨을 보지 않습니다.

임시로 캔버스 연출(발밑 고리·반짝임·3%씩 커짐)을 넣어 뒀지만, 그림 자체가 달라지는 것과는
다릅니다. 진짜 진화 외형을 받고 싶습니다.

## 티어 기준은 이미 정해져 있습니다

레벨 1마다 바꾸면 변화가 안 읽혀서 **마일스톤**을 단위로 씁니다. 이 지점은 이미 공격력
보너스를 주는 자리라, 보이는 변화와 보상이 같이 옵니다.

| 티어 | 레벨 | 지금 캔버스 연출 |
|---|---|---|
| 0 | 0~9 | 없음 |
| 1 | 10~24 | 동색 고리 |
| 2 | 25~49 | 은색 고리 |
| 3 | 50~74 | 금색 고리 + 반짝임 |
| 4 | 75~99 | 보라 고리 + 반짝임 |
| 5 | 100~ | 분홍 고리 + 반짝임 + ✦ 표식 |

## 만들 것

**티어 3개 × 10종 × 포즈 4장 = 120장**을 요청합니다. 0~5 를 전부 그리면 240장이라 과합니다.
아래처럼 묶어 주세요:

| 외형 단계 | 쓰는 티어 | 파일명 |
|---|---|---|
| 기본 | 0~1 | **기존 파일 그대로** (`idle_1.png` 등) — 건드리지 마세요 |
| 2단계 | 2~3 | `<key>/t2_idle_1.png` · `t2_attack_1.png` · `t2_hit_1.png` · `t2_dead_1.png` |
| 3단계 | 4~5 | `<key>/t3_idle_1.png` · … |

10종 키: `slime` 글룹 · `goblin` 그릭 · `bat` 나이트윙 · `mushroom` 스포어링 ·
`skeleton` 본가드 · `wolf` 팽울프 · `ghost` 레이스 · `orc` 브락 · `golem` 그래니트 ·
`dragon` 이그나리온

## 지켜야 할 것

- **규격은 기존과 동일**해야 합니다. `assets/mon/<key>/idle_1.png` 를 열어 같은 캔버스 크기,
  같은 여백, **같은 발 위치**로 그려 주세요. 발이 뜨면 레벨을 올리는 순간 캐릭터가 떠 보입니다.
  (렌더러는 `manifest.json` 의 `box` 로 크기를 맞추는데, 그 값은 `idle` 에서만 계산합니다.)
- **같은 몬스터로 읽혀야** 합니다. 다른 생물이 되면 "진화" 가 아니라 "교체" 로 보입니다.
  실루엣과 주요 색은 유지하고 **덧붙이는 쪽**으로 가 주세요 — 뿔·갑주·문양·발광처럼.
- 단계가 오를수록 **크고 화려하게**. 2단계는 장식 추가, 3단계는 형태 변화까지 허용합니다.
- 배경 투명 PNG, 알파 유지. 팔레트로 줄이지 마세요 — 변환은 이쪽에서 합니다.
- 화풍은 기존 몬스터 그림과 같아야 합니다. `assets/mon/<key>/idle_1.png` 를 참조로 쓰세요.

## 넘겨줄 곳

```
D:/AI/workspace/game/games/output/monster-idle/mon-evo-v1/
  <key>_t2_idle.png · <key>_t2_attack.png · <key>_t2_hit.png · <key>_t2_dead.png
  <key>_t3_idle.png · …
```

한 종씩 끊어 주셔도 됩니다 — 단계 그림이 없으면 기본 그림으로 폴백하도록 만들 예정이라
일부만 와도 게임이 안 깨집니다.

## 이쪽에서 할 일

받으면 ① 규격·발 위치를 기존 그림과 대조하고 ② `sprites.js` 가 티어에 따라 `t2_`/`t3_`
접두사를 고르게 하고 ③ 없으면 기본으로 폴백시키고 ④ 레벨을 올려 가며 전환이 튀지 않는지
확인하고 ⑤ 용량을 재서 변환합니다.

## 검수에서 떨어뜨릴 조건

- 발 위치가 기존과 다름 (레벨업 순간 캐릭터가 뜨거나 가라앉음)
- 캔버스 크기·여백이 기존과 다름
- 다른 생물로 보임 (실루엣·주요 색이 유지되지 않음)
- 배경이 불투명하거나 알파가 깨짐
- 포즈 4종이 서로 다른 크기/위치로 그려짐
