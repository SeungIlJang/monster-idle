# 전투 배경 이미지

여기에 PNG 를 넣으면 **코드 수정 없이** 바로 쓰인다. 없으면 `src/render.js` 가 캔버스로 그리는
기본 배경(하늘·언덕·나무·풀)이 그대로 나온다. 한 장씩 넣어가며 교체할 수 있다.

## 넣는 법

생성한 원본을 그대로 복사하지 말고 변환기를 거친다. 9:5 크롭 → 1080x600 축소 → 팔레트 재인코딩까지
한 번에 한다. 1.8MB 원본이 289KB 가 된다 (10장이면 18MB vs 2.9MB — APK 용량에 그대로 들어간다).

```bash
node tools/make-bg.mjs "D:/AI/workspace/game/games/output/monster-idle/battle-swamp-v1.png" swamp
```

`--rgb` 를 붙이면 팔레트 없이 풀컬러로 저장한다. 색 수가 많아 팔레트 결과에 밴딩이 보일 때만 쓴다.

## 파일 이름

`src/balance.json` 의 `zones.list[].key` 와 같은 이름이어야 한다. 챕터 10개마다 순환한다.

| 파일 | 지역 | 챕터 | 상태 |
|---|---|---|---|
| `forest.png` | 몬스터 숲 | 1, 11, 21 … | ✅ |
| `swamp.png` | 버섯 늪 | 2, 12, 22 … | — |
| `highland.png` | 바람 언덕 | 3, 13 … | — |
| `cave.png` | 해골 동굴 | 4, 14 … | — |
| `canyon.png` | 불타는 협곡 | 5, 15 … | — |
| `frost.png` | 서리 평원 | 6, 16 … | — |
| `shadow.png` | 그림자 숲 | 7, 17 … | — |
| `ruins.png` | 폐허 마을 | 8, 18 … | — |
| `lava.png` | 용암 지대 | 9, 19 … | — |
| `sky.png` | 하늘 성채 | 10, 20 … | — |

## 규격

- **비율 9:5 가로** (예: 1080×600). 캔버스에 `cover` 로 맞추므로 가장자리가 조금 잘릴 수 있다.
- 캐릭터가 **화면 높이의 70% 지점**에 선다. 그 선 아래는 땅, 위는 하늘/배경이 되도록 그릴 것.
- 가운데~오른쪽은 캐릭터가 서는 자리라 **복잡한 요소를 두지 말 것**.
- 글자·UI·캐릭터를 넣지 말 것. 배경만.
- PNG, 500KB 이하 권장 (10장이면 5MB — 앱 용량에 바로 반영된다).

## 확인

```bash
npm run dev     # http://localhost:5180
```

배경을 넣고 새로고침하면 바로 보인다. 챕터를 바꿔 보려면 브라우저 콘솔에서:

```js
const st = await import('/src/state.js'); st.S.st = 21; location.reload();   // 3번째 지역
```

## 생성 프롬프트

`prompts.json` 에 10개 지역의 프롬프트가 들어 있다. 공통 제약(구도·빈 중앙·글자 없음)은 같고
지형 묘사만 다르다. 생성 후 실제로 쓴 프롬프트와 결과를 그 파일에 남겨둘 것.
